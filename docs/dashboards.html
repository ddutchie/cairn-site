Dashboards Removed in 3.1.3

Live HTML dashboards were removed from Cairn in version 3.1.3. Anything you built is kept — each dashboard became a regular note.

Why they were removed

Dashboards were rarely used, so the New Dashboard button, the template picker, the in-app HTML editor and the window.cairn live-data bridge are gone. The AI no longer offers create_dashboard, update_dashboard or get_dashboard_constants in chat, the coding agent or the MCP server, which also trims the tool definitions sent with every request.

What happened to my existing dashboards

On first launch after updating, each dashboard is converted into a regular markdown note with the same title, project and folder. The original HTML is kept in a code block, with a short line at the top explaining what happened, and the note gets its .md file like any other note. Dashboards that arrive via sync from a device still on an older version are converted the next time Cairn starts.

To see the page again, save the code block as an .html file and open it in a browser. It can no longer pull live Cairn data.

What to use instead

  • The project Overview — shows task flow, priorities, what shipped this week and what is at risk.
  • Insights — analytics canvases over your tasks, notes and activity.
  • Board and Calendar — filter and save views of your tasks.
  • Usage — token, cost and request tracking for AI calls.
